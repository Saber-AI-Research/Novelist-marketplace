# Pomodoro Timer

A writing timer using the Pomodoro technique to help you stay focused.

This is draft seed metadata for the registry submission format. The entry is
omitted from `registry.json` and cannot be installed from the marketplace.
Publishing it requires a release ZIP and removal of the draft status.

## Intended Features

- 25-minute focus sessions with 5-minute breaks
- Customizable session and break durations
- Visual countdown timer in the sidebar
- Notification when sessions end
- Session history tracking

## Intended Usage After Publication

1. Enable the Pomodoro Timer plugin in Settings > Plugins
2. Click the timer icon in the sidebar
3. Press Start to begin a focus session
4. Write until the timer ends
5. Take a break when prompted

## Permissions

- **ui** — Display the timer panel in the sidebar
