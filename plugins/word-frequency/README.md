# Word Frequency

Analyze word frequency in your Novelist document.

This is draft seed metadata for the registry submission format. The entry is
omitted from `registry.json` and cannot be installed from the marketplace.
Publishing it requires a release ZIP and removal of the draft status.

## Intended Features

- Count occurrences of each word in the current document
- Display results sorted by frequency
- Highlight overused words
- Export frequency data as CSV

## Intended Usage After Publication

1. Open a document in Novelist
2. Enable the Word Frequency plugin in Settings > Plugins
3. Click the Word Frequency icon in the sidebar
4. View the frequency analysis panel

## Permissions

- **read** — Access document content for analysis
- **ui** — Display the frequency analysis panel
